# Marubako 行为说明

这份文档记录 Marubako 当前的行为：每一条写的是用户能看到的结果，以及背后的取舍。它原本是项目的 README，在第一次公开发布时挪到这里；README 现在只讲「是什么、怎么装、怎么用」。

读者是作者、维护者和 AI 助手：改动行为之前先看这里有没有对应的条目，改完以后同步更新。普通用户请读 [README](../README.zh-CN.md)（English: [README](../README.md)，日本語: [README](../README.ja.md)）。

文中的 `quicklaunch-data.json`、`window.quickLaunch`、`QUICKLAUNCH_*` 是项目更名前留下的内部标识，保留原名是有意的，用户看不到它们。

## 使用方式（当前行为）

- 安装版从 GitHub Releases 下载 `Marubako-Setup-<版本>.exe`，从桌面或开始菜单启动（下载和安装步骤见 [README](../README.zh-CN.md)）。从源码运行见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
- `Ctrl + Shift + Space` 从任何应用唤起 Marubako 主面板，再按一次收起为悬浮球（关闭悬浮球后直接隐藏到系统托盘）。这个快捷键可以在设置的「启动与操作」页更改或关掉：点「更改」后直接按下新的组合键（至少两个修饰键，例如 `Ctrl + Alt + 字母`；不能只有 Shift，也不能是 Windows 保留的组合），按下时就会向系统试注册一次，已被其他程序占用的组合当场拒绝，不能保存；点「恢复默认」回到 `Ctrl + Shift + Space`，关掉开关则不注册任何全局快捷键（选好的组合保留，重新打开即可）。不再偷偷改用别的组合：默认组合被别的程序占着时，设置页会写明“已被其他程序占用”，托盘提示和首次启动的上手卡片也不再提这个键，再次打开设置时会重试注册。托盘图标的提示文字和首次提示都跟着当前设置。也可随时从托盘打开。快捷键呼出不再自动打开搜索，连触发会被合并。
- `Ctrl + K` 搜索所有显示中的分类、分组、备忘内容和任务（被隐藏的分类不会被搜到）；方向键选择，每一行右侧写明回车会做什么：文件夹、网站、软件是「启动」，命令和备忘是「复制」内容，密码条目是「复制密码」（没有可复制内容的条目改为进入编辑），分组和任务是「查看」；`Shift + 回车`或行尾的铅笔按钮进入编辑；按住 `Alt` 时前九行显示数字，`Alt + 数字` 直接执行那一行。输入框为空时列出「最近使用」（最近启动或从搜索复制过的条目，最多 8 个，已删除或被隐藏的会跳过），没有记录时列出当前分类的前 8 个条目。多个词按词计分、整名匹配排在前面，分组的条目数不再参与匹配。搜索不会索引或显示密码内容，只在你按回车时才把密码复制到剪贴板（不会自动清除剪贴板）。从搜索启动条目成功后，若开启了「打开条目后自动收起」，面板照常收成悬浮球。
- `Alt + 1–7` 按顺序切换当前显示的分类（七个都显示时命令为 5，备忘为 6，任务为 7；隐藏了分类后只数还显示的），`Ctrl + N` 添加当前分类的条目或任务，`Esc` 关闭弹窗或把面板收成悬浮球。条目、分组、任务和子任务的表单里有改动没保存时，`Esc`、点右上角的叉、点「取消」或点弹窗外的暗处都不会直接丢掉输入，而是在弹窗里问一句「放弃未保存的修改？」（再按一次 `Esc` 等于「继续编辑」）；在输入框里拖选文字或在设置里拖滑块，松手时鼠标滑出了弹窗也不会关掉它。
- 窗口底部没有常驻状态栏，也没有浮在右下角的提示框。只有需要告诉你什么时，才从底边升起一条反馈条，占用内容区的高度而不盖住卡片，平时高度为 0：保存到磁盘失败时红色常驻并带「重试」；删除后的「撤销」6 秒；其余提示约 2 秒，鼠标停在上面会暂停。文字最多两行，悬停可看全文。设置、搜索或分组弹层打开时，遮罩止于反馈条上沿，条上的消息始终看得见。编辑和设置的保存成功不再提示（复制成功直接在被按的按钮上显示对勾）；新建条目、粘贴或拖入添加、把条目移到别处这几种会说一句「已添加…」「已把…移到…」并带 6 秒的「撤销」。「数据保存在本机」移到设置「语言与数据」页的第一行。写入失败以外的启动提示（数据被重置、从备份恢复、密码需要重新输入）仍留在窗口顶部，读完点「知道了」。
- 在条目或分组上点右键（或聚焦后按菜单键、`Shift + F10`）弹出原生菜单：启动或复制、「重命名 / 编辑…」（`F2`）、「移到分组」（子菜单里是其他分组和「独立条目」，移动后底部给出「已移到…」和撤销）、「删除」（`Del`）；分组的菜单是打开、重命名、删除。聚焦在条目上直接按 `F2` 打开编辑，按 `Delete` 删除（输入框里不响应）。移动条目不必再拖拽。
- 删除条目或分组会立即生效，并在底部反馈条给出 6 秒的「撤销」按钮，也可以按 `Ctrl + Z` 撤销最近一次删除；只有包含条目的分组会先确认一次。无法在这台电脑上解密的密码条目删除后不能撤销，会先单独确认。
- 点开条目失败时（文件夹被移走、U 盘没插、软件被卸载、网址写错），底部反馈条用当前语言说明是哪个条目、哪里不对（找不到路径、路径中有一段不是文件夹、没有权限、找不到程序、网址无效、可能没有与之关联的程序），不再显示英文的原始报错；它停留约 12 秒（鼠标停在上面会暂停），并带「编辑」按钮：点它打开该条目的编辑框，光标已在出问题的路径或网址框里，原有文字处于选中状态，直接粘贴新的即可。
- 路径框会清理粘贴来的内容，保存的是能用的路径：去掉资源管理器「复制为路径」带的引号、首尾空格和看不见的方向符，把 `file:///` 地址变成路径；`%USERPROFILE%` 这类环境变量按原样保存、打开时才展开（换账号或换电脑也有效），没有定义的变量保持原样并提示找不到；UNC 路径（`\\server\share`）不变。离开路径框时就能看到清理后的结果，之前保存过带引号的条目也能直接打开。
- 标题栏右侧只有两个出口：收起按钮（紫色，画成悬浮球的形状，与 `Esc` 相同）把面板收成悬浮球，关闭按钮把面板隐藏到系统托盘。悬浮球默认常驻，这两个出口以及快捷键、点开条目后自动收起都不会把它藏起来，只有在设置里关掉「收起时显示悬浮球」才会没有球。标题栏没有最小化按钮；从任务栏或 `Win + D` 最小化面板时球照常显示，还原后状态同步。右键悬浮球或系统托盘图标打开相同菜单，包含「打开 Marubako」和「退出 (Quit)」；Quit 会保存待写入数据并完全退出。菜单打开期间暂停临时面板的自动收起。菜单文字以及系统对话框（选择文件夹或程序、导出、导入、启动失败）的文字都跟随设置里的语言，切换语言后托盘菜单和悬浮球菜单立即换成新语言，不需要重启。
- 设置分为「外观」「启动与操作」「语言与数据」；条目排列（网格 / 列表）在「外观」里，新安装默认是列表。文件夹、网站、软件三页的操作按钮里也有一个切换按钮（在「新建分组」左边），点一下就在网格和列表之间切换，图标和提示写的是点了之后会变成哪一种，和设置里的是同一个选项。「主题」有浅色、深色和「跟随系统」三个选项，新安装默认浅色；选「跟随系统」时，Windows 切换浅色 / 深色模式，面板和悬浮球跟着变，不用重启。设置里其余选项点「保存」才生效，只有「外观」页的主题、强调色、界面大小、不透明度、动效时长会在拖动或点选时立刻预览，取消、按 `Esc` 或点关闭会还原，保存后保留；保存后设置窗口关闭（预览已经让你看到了效果）。「面板保持置顶」与标题栏的图钉是同一个动作，立即生效，不属于保存/取消。「界面大小」只缩放主窗口，弹窗和搜索保持原大小。「不透明度」100% 是完全不透明，最低 40%（再低面板几乎看不见）。「动效时长」以标准时长为 100%（60%–160%），数值越小动画越快。「外观」里的「强调色」是六个实心圆点（紫罗兰、珊瑚橙、青、海蓝、石墨、Monokai），新安装默认石墨；圆点就是选中后的颜色，选中的那个有外圈和对勾，不只靠颜色区分。前五种只换界面里的强调色（选中态、主按钮、焦点环）；Monokai 是一整套配色：深色主题下是暖灰底配黄色，浅色主题下是同一家族的米色底，底色、文字和命令代码的着色都跟着换，黄色按钮上用深色字。不再有背景光斑，悬浮球、小圆点和标题栏图标始终是应用图标的紫色。旧版本保存的「背景」选择按原键继续生效：极光为紫罗兰、日落为珊瑚橙、森林为青（不再是靛蓝）、海洋为海蓝、简约为石墨。安装版可启用开机启动，登录后在桌面显示悬浮球（关闭悬浮球时在系统托盘待命）。也可启用打开条目后自动收起（有悬浮球时收成球，没有时回到托盘）。「收起时显示悬浮球」默认开启；关闭后快捷键、`Esc` 和收起按钮直接把面板隐藏到系统托盘，拖到屏幕边缘也不再收成球，首次隐藏到托盘时会弹出一次托盘提示。保存后立即生效，不需要重启。
- 内容上方只有两条固定栏。第一行（36 像素）是窗口行：全局搜索、可拖动窗口的空白区、置顶、设置、收起按钮和关闭按钮，没有 Logo 和字标。第二行是分类行，默认显示七个分类。设置「外观」页的「显示的分类」可以逐个关掉，至少保留一个：被隐藏的分类不出现在页签、全局搜索、`Alt + 数字` 和「添加」里，但数据一条都不会删，重新打开后全部回来；正在看的分类被隐藏时自动切到第一个还显示的分类，启动时也从第一个显示的分类开始。分类上不再显示数量，名称、分组数、条目数和快捷键写在悬停提示里（如「文件夹 · 2 个分组 3 个条目 · Alt+1」）。每个分类页没有标题行和页内筛选框，第一个条目紧贴分类行；找东西统一用 `Ctrl + K` 的全局搜索。任务页只有「添加任务」。
- 分类行的样子由窗口宽度决定，宽度门槛按语言写成常量（`src/shared/layout-widths.ts`，在真实窗口里实测，运行时不量）。默认的细长窗口里图标在上、名称在下，七个页签等宽，这一排 52 像素高，「新建分组」和「添加」放在第一行搜索右边；拉宽到图标和名称可以并排时（中文约 644 像素起，日文 700、英文 740）改成 40 像素高的一行，这两个按钮回到分类行右端；比名称需要的宽度更窄时（日文低于 370、英文低于 460，中文只有放大界面时才会遇到）只显示图标，名称在悬停提示里。上面这些门槛是七个分类的值；隐藏了分类后按剩下的个数缩小（`stackedMinWidth`、`rowMinWidth`），所以只剩几个分类时，默认的细长窗口也能把图标和名称排成一行。搜索入口在窗口宽度小于 454 像素时只剩放大镜。界面放大到窗口内容宽度不足 262 像素时（正常大小下不会遇到），第一行不再放网格 / 列表切换按钮，只在设置里切换。文件夹和软件支持浏览选择路径，网址可省略 `https://`。
- 新安装默认打开细长的窗口：中文 400 × 720，日文 400 × 720，英文 470 × 720（名称更长），高度不超过屏幕可用高度减去边距；窗口停在屏幕右侧，悬浮球从第一秒起就在它右边（贴着屏幕右边缘，两者垂直居中，间隔 8 像素），球是展开时的小圆点，收起和展开都不会挪动它们；只有关掉「收起时显示悬浮球」时才没有球，窗口回到屏幕正中。已经保存过窗口位置和大小的用户不受影响。面板最小宽度 320 像素。
- 新安装的界面语言跟随系统：系统语言是中文（zh 开头）用中文，日文（ja 开头）用日文，其余一律用英文。示例分组、示例条目和「使用说明」不随语言变化，在任何系统上都是同一套英文（示例网站是 Google、GitHub 和 YouTube）：这样即使语言识别得不准，示例也不会是你意想不到的语言。示例里每个分类都有内容：文件夹（桌面、文档、下载）、网站、软件（PowerShell 和命令提示符）、一个示例账号、一条示例命令（刷新 DNS 缓存）和一条使用说明。已有数据保持原来的语言。在设置里换语言（或调大界面、增减分类）后，如果原来的窗口宽度放不下分类名称，窗口会自动加宽到刚好能显示名称，靠悬浮球的一侧不动。载入画面和第一帧用保存的语言，文档语言（`<html lang>`）随之设置，日文界面优先使用日文字体。第一次启动时分类行下方有一张可以关闭的卡片，里面用三种语言各自的写法「中文 / English / 日本語」排成一行，点哪个就切到哪个；设置里的语言选项仍在「语言与数据」页。
- 第一次启动（新安装）时，分类行下方有一张可以永久关掉的「上手卡片」，三行字，每做到一件就打勾：添加第一个条目（加什么、怎么加都算）；把面板收成悬浮球再打开（单击球预览，双击保持打开）；用全局快捷键唤起面板（显示实际生效的组合；快捷键注册不上时没有这一行；关掉悬浮球时也没有第二行）。做完后卡片显示「都学会了」，1.2 秒后自己收起；右上角的「×」随时可以关掉，之后不再出现。卡片的状态存在窗口的本地存储里（键 `onboarding-v1`），和其他首次提示放在一起；从旧版本升级、已有数据的安装不会看到它。它取代了原来的「安装版第一次启动的提示」。e2e 默认仍是原来的首次启动（中文、没有卡片和球、窗口居中），好让其他用例的起点不变；用例可以用环境变量 `QUICKLAUNCH_LOCALE=en-US` 假装另一台电脑的语言，用 `QUICKLAUNCH_FIRST_RUN=1` 打开首次启动的球布局和卡片（`e2e/first-run.spec.ts`）。
- 没有内容的分类页（软件、命令、任务等）在标题和「添加」按钮之间有一句话，说这一页做什么用；搜索没有结果时不显示。
- 入口采用横向小卡片，命令、备忘与列表条目在宽窗口中并排显示，窄窗口自动改成单列。命令默认预览两行，可展开查看完整脚本；复制始终包含全部代码。
- 账号卡片分成「账号」「密码」两行，点击对应行即可分别复制；密码保持隐藏，仍可查看、编辑和删除。没有账号时复制账号按钮禁用。
- 密码只是**便捷存放，不是密码管理器**：它们只保存在这台电脑上，用当前 Windows 账户加密；能登录这个 Windows 账户的人都可以查看，重要账号请使用专门的密码管理器。这段话显示在「密码」分类页顶部，点它右上角的 × 关掉后不再出现（记在窗口的本地存储里；以前把它折叠起来的人也不会再看到）；新增、编辑密码条目的提示里一直写着同样的话。没有主密码或应用锁，复制密码后也不会清空剪贴板。悬浮球的窗口读不到数据文件（它只向主进程要语言和主题），读写、导出、导入数据的通道只接受主面板的请求。
- 卡片行距收紧到 6 像素。主题使用更柔和的悬停底色与清晰的键盘焦点描边；新安装默认是浅色主题加石墨强调色。
- 切换分类时，新的一页从它在分类行里所在的那一侧滑进来一小段并淡入（往右边的分类切就从右边来，往左就从左边来），整页一起动，和上面标记的移动方向一致；启动后的第一页直接显示，没有动画。分组和任务的内容区只有在你点开它时才有展开动画，切换分类时已经展开的分组不再各自往下展开。
- 文件夹、网站、软件的网格视图用 44 像素高的单行磁贴：24 像素图标加一行名称，名称过长时省略；分组在右侧用淡色数字显示条目数，并以柔和的强调色底与独立条目区分。路径、网址和条目数不再占第二行，写在悬停提示和无障碍名称里（列表视图仍显示两行）。分组弹层使用同样的磁贴。栅格按宽度自动分列：约 400 像素宽的窄窗口排两列，放宽后列数自动增加。操作按钮在鼠标停留约 0.15 秒后出现在磁贴右侧、垂直居中，盖住名称末尾，名称不会因此改变宽度。把独立条目拖到分组磁贴上（两侧各 14 像素的边缘除外）即放入该分组，落在边缘或磁贴之间则排在分组前后。
- 把标题栏拖到屏幕左右边缘，或点击标题栏右侧的紫色收起按钮，可收起为悬浮球：画出来的球是 30 像素，外面的透明窗口是 40 × 40 像素（Windows 不允许窗口比这更矮）。球始终置顶，可自由拖动；只有距左右边缘 24 像素内松手才吸附。面板打开时，球和面板是一对：拖标题栏移动面板，球实时跟着走；拖球，面板也实时跟着走，松手后面板留在球旁边原来的位置，只有屏幕放不下时才重新摆到球的另一侧或避让屏幕边界。展开、收起与调整面板宽高均不会移动球。收起后再展开，面板回到上次在球旁边的位置；只有球在收起期间被拖走了，才按球的新位置重新摆放。重启后球会恢复：上次停在悬浮球状态时，下次启动（包括开机自启）直接在原位置显示球而不弹出面板；开机自启（`--hidden`）总会带出球，只要没有关掉它。
- 单击悬浮球临时展开，鼠标离开球与面板区域默认等待 200 毫秒开始收回原位置；两者之间的间隙也算操作区域。指针刚滑出边缘不到 28 像素时多半是手滑，会多等至少 450 毫秒，再远则按设置的延迟。在设置的「启动与操作 → 自动收起延迟」中可调整为 0–2000 毫秒，0 表示两个区域都立即开始收起动画，保存后生效。编辑、弹窗、菜单、拖动、保存和键盘操作期间暂停自动收起。双击（两击间隔 500 毫秒内）将临时面板转为保持打开的普通窗口，不自动置顶；临时面板展开时单击球会先等 250 毫秒再收起，好让第二击来得及变成双击；已经保持打开的面板（双击打开的，或已置顶）单击立刻收起。开启置顶也会暂停自动收起，取消置顶后临时模式恢复收起，普通窗口仍保持打开。保持打开的普通窗口被其他窗口盖住时，单击球先把它带到最前面，再单击才收起；临时面板和置顶的面板仍是单击即收起。首次启动、快捷键及托盘唤回采用普通窗口模式。新用户默认不置顶，已有置顶设置会保留。
- 悬浮球的悬停提示、设置说明和首次启动的上手卡片会介绍单击和双击的区别；面板展开时悬停提示改为「单击收起」。面板是保持打开的（双击打开的，或已置顶）时，单击球立刻收起，没有等待；只有临时展开的面板会等约四分之一秒，好让第二下点击把它变成保持打开。卡片已经关掉的用户，第一次临时展开时还会看到 6 秒的提示。大标题下的装饰性说明已移除。
- 悬浮球直接画成应用图标的形状：紫色渐变的圆角方块，左下角是整圆，里面一个白点，不再放图片。按下即缩小，松手后以弹簧动画回弹到目标；展开时三个圆角变成整圆、白点淡出，缩成原位置的紫色圆点，收起时反向恢复并略微弹过原大小。仅绘制层缩放，原位置及 30 像素点击、拖动区域保持不变；形状变化与淡出不回弹。系统启用减少动态效果时没有缩放，面板只做 100 毫秒淡入、60 毫秒淡出，球瞬时切换。
- 窗口圆角使用 Chromium 的透明度抗锯齿。展开时面板以球心为原点，用缩放加透明度的弹簧动画弹出，由合成线程绘制，不再使用裁剪动画，文字大小几乎不变；动画一开始面板就可点击、可输入。收起比展开快：面板先缩回消失，球随后回弹接住。设置里的「动效时长」按比例拉伸所有时长，回弹的像素幅度不随设置变化。原生窗口先准备绘制再播放动画，球保持可见；没有整窗变暗与文字挤压。拖动由主进程读取系统鼠标位置，松手、取消或失去焦点时清理状态，鼠标捕获失败也能继续点击。图标使用无外框按钮，键盘焦点以白色加深色的双层描边表示。
- 启动载入显示应用图标与逐张出现的小卡片动画；系统启用减少动态效果时显示静态版本。
- 新增／编辑条目使用统一的分类标题、保存位置、分区表单和固定底栏。小窗口中内容区独立滚动，保存按钮始终可见；六类条目均支持 `Ctrl + S` 保存。名称、路径、网址或命令代码缺失、格式不对时，原因写在对应输入框的正下方（输入框描红，读屏软件会读到），光标自动落到第一个出错的字段，一改动就消失；复制为路径带来的引号会自动去掉，路径必须是完整路径（`C:\Work`、`\\服务器\共享`，或以 `%变量%` 开头），已保存的老条目不改路径时照常保存；没写协议的网址补 `https://`，`localhost` 和内网地址补 `http://`。分组、任务和子任务表单同样可以回车或 `Ctrl + S` 保存，名称为空时有提示，写盘失败时窗口不会关掉。
- 添加文件夹、软件、网站时表单先问目标：打开后光标就在路径或网址框里，粘贴即可，首尾的引号会去掉，网址补全协议；名称不用填，留空就按目标自动取（网站取域名，文件夹取最后一级目录名，软件取文件名去掉扩展名），自动取的名字在改目标时会跟着变，自己改过的名字不会被覆盖。「保存到」是个下拉框（独立条目或本分类的某个分组），默认是点「添加」的位置（工具栏为独立条目，分组里的「＋」为该分组）；编辑已有条目时改它就是把条目移过去，底部反馈条带「撤销」。新建条目保存后反馈条会写「已添加「…」」并带「撤销」；`Ctrl + Enter` 保存并继续添加，表单清空、光标回到目标框，连续添加多个只开一次弹窗。命令、备忘、密码的表单仍是名称在前，名称必填，也没有 `Ctrl + Enter`。
- 不开表单也能添加：面板在前台、光标不在输入框里时按 `Ctrl + V`，剪贴板里的网址（带 `http://` 或 `https://`）或完整路径（盘符路径、`\\服务器\共享`，带不带引号都行，资源管理器里「复制为路径」选多个文件时每行一个）会直接添加成条目；也可以把文件、文件夹、`.url` 网址快捷方式或浏览器地址栏里的网址拖到面板上。程序（`.exe`、`.lnk`、`.bat`、`.cmd`）进「软件」，文件夹进「文件夹」，网址进「网站」，其它文件按文件夹的方式进「文件夹」（用自己的程序打开，图标是文件图标）；当前页不是对应分类时自动切过去。落在分组卡片上、或者分组弹层开着时放进那个分组，否则作为独立条目。拖入时内容区出现虚线落区和「松开以添加」，悬停在分组上时那张卡片描边并写「添加到「分组名」」，临时展开的面板在拖入期间不会收回。已经有的路径（不分大小写、斜杠和末尾的反斜杠）或网址不会重复添加，会写「已添加 2 项，1 项已存在」。底部反馈条写「已添加 …」并带「撤销」；不是网址或路径的普通文本照常粘贴，不会被当成添加。悬浮球上的拖放暂未支持，先展开面板（单击球后移开鼠标面板会收回，双击球保持打开）再拖。
- 面板里的输入框和文本框可以右键：「剪切」「复制」「粘贴」「全选」，用当前界面语言，能做的才可点（密码框不能剪切和复制，剪贴板为空不能粘贴）；不是输入框的地方，只有选中了文字时才出现一个「复制」，其余位置没有右键菜单。弹出菜单期间，临时展开的面板不会因为鼠标移到菜单上而收回。输入框的拼写检查已关闭（框里多是路径、网址、账号和命令，红色波浪线只会添乱）。
- 任务：任务卡片最左的方格点一下就完成，再点一下回到「待办」，只改这个任务，子任务保持原样。子任务前面的方格也是点一下打勾、再点取消打勾；「进行中」和「跳过」在编辑子任务的弹窗里选，不再需要连点三下。任务的状态只由你来改，子任务不会悄悄改它：勾完最后一个子任务时，底部反馈条会问「子任务都完成了　标记任务完成」；已经完成的任务里有子任务被重新打开（或新加了一个）时，会问「任务已完成，但有子任务没完成　重新打开任务」；不点就什么也不会变。新建任务的弹窗里也能选日期，默认是正在看的那一天，选了别的日子，保存后底部会提示「已添加到 …」。
- 标题栏、启动画面、托盘、窗口与安装图标采用统一的应用图标：紫色渐变的圆角方块，左下角是一个大圆角，里面一个白点。提供 16–256 像素多尺寸资源，16–24 像素使用白点更大的小尺寸版。修改 `src/renderer/src/assets/marubako.svg` 或 `marubako-small.svg` 后，运行 `npm run icons`（即 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/generate-icons.ps1`，需要 Windows PowerShell 5.1；默认的执行策略会拒绝直接运行脚本）重新生成 PNG 和 ICO；托盘按显示缩放使用匹配的尺寸。
- 「命令」独立于备忘，支持 PowerShell、Bash、Batch、Python、JavaScript、TypeScript、SQL、JSON、YAML 和纯文本。可填写用途说明、分组整理、搜索代码和一键复制原始脚本；只记录与复制，不执行脚本。
- 代码编辑器提供等宽字体、行号、自动换行、两空格缩进与回车保持缩进；`Tab` 缩进、`Shift + Tab` 取消缩进、`Ctrl + S` 保存、`Ctrl + Tab` 移至保存按钮。代码卡片提供语法高亮和展开预览。旧版本数据和备忘会自动保留。
- 在源码目录的 `scripts` 文件夹里双击 `Marubako.vbs` 或 `start.bat`，会无控制台启动。脚本会检查源码更新时间，优先使用最新的打包版本，必要时重建源码，避免启动旧界面。

## 数据与备份

数据完全在本机，位于 `%APPDATA%\marubako\`：

| 文件                                      | 内容                                                                                            |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `quicklaunch-data.json`                   | 全部内容。普通 JSON，可以用记事本打开；只有每条密码单独加密，备忘、命令、网址、任务等都是明文。 |
| `window-state.json`                       | 窗口位置、大小、置顶状态和悬浮球位置。                                                          |
| `quicklaunch-data.json.bak`               | 上一次成功启动时数据文件的副本。从 2.5.x 升级后的第一次启动，它还是旧的整体加密格式。           |
| `backups\`                                | 每天一份自动备份（保留最近 7 天），以及每次导入前的备份（保留最近 3 份）。                      |
| `quicklaunch-data.json.recovery-<时间戳>` | 数据文件无法读取、并被你选择替换时，原文件的副本。                                              |
| `logs\main.log`                           | 主进程日志。                                                                                    |

- 写入是先写临时文件、再整体替换，所以写到一半断电、崩溃或被结束进程，都不会留下半截文件。写盘失败时界面会显示“保存失败”并自动重试；退出时如果仍然写不进去，会先询问你。
- 密码用 Windows 账号绑定的密钥加密，只能在同一台电脑、同一个 Windows 账号下读取。换电脑、重装系统或换账号后，其余数据照常打开，密码会显示“需要重新填写”，原来的密文仍保留在文件里。
- 换电脑或重装系统之前，请用「设置 → 语言与数据 → 导出数据」，到新电脑后再「导入数据」。导出的文件是**未加密的 JSON**。数据里有密码时，导出前会先弹出提示，让你选「不含密码导出」（默认按钮）、「含密码导出」或取消：含密码的文件里每条密码都是明文，请自行妥善保管，不要放进会自动同步的网盘目录，也不要发给别人；想把密码带到另一台电脑，必须选「含密码导出」。不含密码的文件会在里面留下标记，导入它时会提示“这个文件不含密码，导入后所有密码条目的密码都是空的”。导入时先检查文件是否是数据文件，再在系统对话框里确认（默认按钮是「取消」），并自动备份当前数据。
- 直接复制 `%APPDATA%\marubako\` 目录，只在同一台电脑、同一个 Windows 账号下有意义，不能用来迁移。
- 开发构建（`npm run dev`、`electron .`）不使用上面的目录，而是使用 `%APPDATA%\marubako-dev\`，不会读写正式版的数据，也不会和已安装的正式版抢单实例锁。设置了环境变量 `QUICKLAUNCH_USER_DATA` 时以它为准（e2e 和打包冒烟测试都这样用）。

## 故障排查

- 启动时无法读取数据文件：应用不会自动覆盖它，而是弹出选择——「退出（保留原文件）」「从自动备份恢复」「用默认数据开始」。选后两项之前，原文件都会先另存为 `.recovery` 副本。
- 数据看起来丢失：先用「设置 → 语言与数据 → 导入数据」选择 `backups\` 里最近的 `.json` 备份。导入对话框右下角可以切换为“所有文件”，这样也能选 `.bak`。注意：从 2.5.x 升级当天生成的 `.bak` 和当天的备份仍是旧的整体加密格式，只能在同一台电脑、同一个 Windows 账号下导入；`.recovery-*` 是当时无法读取的原文件，只用于手动修复或提交问题时附上，不一定能导入。
- 手动恢复：完全退出应用，先把当前的 `quicklaunch-data.json` 另存一份，再把想用的备份复制成 `quicklaunch-data.json`。
- 启动后界面异常：先复制整个 `%APPDATA%\marubako\` 目录作为备份，再把 `quicklaunch-data.json` 改名为 `quicklaunch-data.old.json` 后重启。因为 `.bak` 和 `backups\` 里还有自动备份，应用会弹出“找不到数据文件，但发现了自动备份”的选择框：选「用默认数据开始」得到全新的默认数据；选「从 … 的备份恢复」会载入最近一份备份，也就是导致问题的同一份数据；选「退出」则什么都不改。旧文件仍在原处。
- 提示“密码需要重新填写”：这些密码是在另一台电脑或另一个 Windows 账号下保存的，这里解不开。重新填写即可；回到原来的电脑，原密码仍可读取。
- 想提交问题：附上复现步骤、预期结果、实际结果，以及 `%APPDATA%\marubako\logs\main.log` 里的相关日志片段。
